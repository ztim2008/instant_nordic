# Nordicbuilder — Bindings (Правила применения): Smoke-checklist (2026-04-06)

Цель: за 2–3 минуты проверить, что экран **Нордик → Правила применения** работает и позволяет править binding rules без SQL.

## Предусловия

- Вы вошли под администратором.
- Активен админский шаблон **admincoreui** (в modern экран будет заглушкой).

URL:

- `/admin/controllers/edit/nordicbuilder/bindings`

## Smoke (5 шагов)

1) **Открытие экрана**
- Открыть URL выше.
- Ожидаемо: страница открывается без 503/фаталов, слева список, справа форма.

2) **Seed examples (создание примеров)**
- Нажать кнопку **Создать примеры**.
- Ожидаемо: появляется сообщение об успехе и в списке появляются минимум:
  - `overlay.content_category.board`
  - `overlay.user_profile.default`

3) **Редактирование + сохранение**
- Открыть `overlay.content_category.board`.
- Изменить `title` (например добавить “TEST”).
- Нажать **Сохранить правило**.
- Ожидаемо: успех-сообщение, после перезагрузки изменения на месте.

4) **Проверка валидации JSON**
- В `matching.route_params (JSON)` вставить заведомо невалидный JSON (например `{`), нажать **Сохранить правило**.
- Ожидаемо: ошибка в форме, правило не перетирается мусором.

5) **Удаление**
- В списке нажать **Удалить** у тестового правила.
- Ожидаемо: confirm, после подтверждения правило исчезает из списка.

6) *(Опционально)* **Создание правила из экрана «Страницы»**
- Админка → **Нордик → Страницы** → **Новая страница**.
- Выбрать «Где применять»: **Главная страница**.
- Создать и открыть канвас.
- Вернуться в **Нордик → Правила применения**.
- Ожидаемо: появилось правило `page.homepage` (или выбранный `binding_key`) и оно указывает на созданный `page_key`.

## Что считать блокером

- 503/фатал при открытии экрана.
- Невозможность создать примеры (CSRF/POST не проходит).
- Сохранение не работает (не обновляет документ или всегда падает в ошибку).
- Удаление не удаляет запись.
