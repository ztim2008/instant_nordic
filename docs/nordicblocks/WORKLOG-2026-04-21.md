## Второй проход: nested authoring, layers UX и palette expansion

### 1. Убран принудительный автовыбор при root context

- В editor shell введён явный `rootInsertionMode`.
- После очистки selection редактор больше не обязан мгновенно перевыбирать первый scene node.
- Это сделало рабочим сценарий `В корень` как осознанный insertion context, а не как мимолётное состояние до следующего renderAll.

### 2. Layers переведены из плоского списка в иерархическую навигацию

- Layers теперь рендерятся как tree по `parentId`, а не как плоский z-index список.
- Добавлены breadcrumbs вида `Сцена / Parent / Child`.
- Для выбранного insertion context показывается отдельный marker `insert`.
- Для container/group узлов показывается child badge, чтобы вложенность читалась без ручного раскрытия DOM.
- В block card и layers card добавлены явные действия:
  - `В корень`
  - `К parent`

### 3. Nested insertion доведён до локального parent scope

- Новый объект в nested flow по-прежнему создаётся от текущего selection context, но теперь это подтверждено реальным tree-navigation loop.
- Для новых вставок z-index теперь назначается локально внутри текущего `parentId`, а не глобально по всей сцене.
- Это убирает лишний drift при вложенной authoring-сцене, где children и root nodes не должны делить один глобальный insertion порядок.

### 4. Palette расширен после UX-стабилизации

## Следующий проход: photo freeform + canvas camera semantics + stage height handle

### Что изменено

- В `design-block-editor.js` для `photo/svg` добавлен новый prop `objectPosition` с пресетами `center / left-top / right-top / left-bottom / right-bottom`.
- Photo в editor больше не держится за corner aspect lock: свободный corner resize теперь разрешает менять width и height независимо.
- Wheel на canvas больше не зумит по умолчанию: обычный wheel двигает камеру по сцене, а `Ctrl/Cmd + wheel` отвечает только за zoom текущего breakpoint.
- При переключении breakpoint viewport теперь сбрасывается в `zoom=100% / offsetX=0 / offsetY=0`, чтобы camera state не протекал между desktop/tablet/mobile.
- В stage overlay добавлен нижний drag handle для изменения `minHeight`; во время drag высота пересчитывается пропорционально для desktop/tablet/mobile stage branches.
- Runtime renderer и contract normalizer обновлены под `photo.objectPosition`, чтобы editor/runtime не расходились по positioning semantics.
- Изменения синхронно внесены в live source и package mirror.

### Что проверено

- `get_errors` по editor JS/CSS и PHP runtime/normalizer не показал новых ошибок.
