## Выбор следующего block type для второй волны

- Для второй волны выбран `headline_feed`.
- Причины выбора:
  - блок добавляет новый полезный сценарий `lead + rail/grid`, а не повторяет уже закрытый pilot `content_feed`;
  - у блока уже есть manifest-first contract, normalizer support, shared shell profile, layout controls и runtime CSS;
  - rollout не требует нового private inspector shell и укладывается в shared contour `manifest -> normalizer -> shared renderers -> SSR -> runtime CSS`.
- `category_cards` сознательно не взят следующим, потому что на этом шаге он слишком близок к уже закрытому пути `content_feed + eyebrow` и слабее расширяет доказанную shared system.
