# NordicBlocks Worklog — 2026-04-16

## Что закрыто за день

### 1. Первый data-driven FAQ vertical slice

- FAQ переведен на contract-first storage и SSR runtime.
- Повторяющиеся элементы живут канонически в `content.items[]`.
- Поднят первый adapter-backed repeater через `data.listSource` + `content_list`.
- Preview, widget runtime, legacy canvas и legacy public view используют один hydration pipeline до `render.php`.

### 2. Runtime и adapter слой

- Добавлены `DataSourceResolver`, `BindingMapper`, `BlockPayloadHydrator`.
- В `model.php` добавлен `hydrateBlockForRender()` для единой подготовки блока перед рендером.
- Для dynamic blocks в legacy public view отключен небезопасный SSR cache reuse.
- Добавлен smoke-скрипт `scripts/nordicblocks-faq-content-list-smoke.php`.

### 3. Backend CRUD и editor hardening

- `block_create`, `block_save`, `block_delete` переведены на явный admin + CSRF контроль.
- V2 shell и список блоков теперь передают CSRF token явно.
- `block_edit` и `block_editor_state` расширены с hero на hero + faq.
- Для canvas-click внутри FAQ сохранено нативное раскрытие `details/summary`.

### 4. Inspector Shell v2

- Исправлен вертикальный скролл правой панели: контент больше не уходит ниже окна.
- Для title и subtitle добавлены реальные настройки:
  - показывать / скрыть;
  - отступ снизу;
  - desktop / mobile отдельно.
- Для FAQ добавлен ручной repeater editor и первая data-binding панель для `content_list`.
- Для section background добавлены режимы:
  - `theme`;
  - solid color;
  - gradient;
  - image + overlay.

### 5. SSR render и стили блоков

- Hero и FAQ рендерят title/subtitle visibility из контракта.
- Hero и FAQ применяют background modes через shared helper.
- Hero и FAQ используют margin variables для title/subtitle.
- FAQ получил align left/center, plain/card item surface и responsive typography hooks.
