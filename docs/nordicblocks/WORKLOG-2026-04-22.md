## Что сделано

### 1. В `design_block` добавлен новый type `embed`

- Новый элемент добавлен в palette как `Вставка`.
- Type зарегистрирован в server-side allowlist normalizer-а и синхронно перенесён в package mirror.
- Для `embed` введены canonical props:
  - `sourceMode = html|url`
  - `code`
  - `url`
  - `title`
  - `lazy`
  - `allowFullscreen`
  - `sandboxProfile = strict|forms|media|trusted`
  - `referrerPolicy`

### 2. Runtime сделан через sandbox iframe, а не через raw HTML в DOM

- `DesignBlockElementRenderer` рендерит `embed` через отдельную iframe-ветку.
- Для `html`-режима используется `srcdoc` с базовой безопасной оболочкой документа.
- Для `url`-режима допускаются только `http/https` iframe URL.
- В runtime добавлены отдельные sandbox/allow профили, чтобы совместимость и изоляция регулировались явно, а не неявным raw HTML output.

### 3. Editor shell получил полный authoring loop для `embed`

- В `design-block-editor.js` добавлены:
  - palette label/type wiring;
  - default branch с размером `480x320`;
  - inspector-секции `Источник` и `Безопасность и runtime`;
  - canvas preview через iframe;
  - placeholder для пустого embed state.
- В `design-block-editor.css` iframe preview переведён в `pointer-events: none`, чтобы embed не перехватывал selection/resize gestures на холсте.

### 4. `embed` расширен до universal provider-aware flow

- В canonical props добавлены:
  - `provider = generic|rutube|vk_video|kinescope`
  - `aspectRatio = free|16:9|4:3|1:1|9:16|21:9`
  - `hideScrollbars`
- В runtime добавлена provider-aware нормализация URL для:
  - Рутуб
  - VK Видео
  - Kinescope
- Для `srcdoc` и iframe preview добавлена опция скрытия прокрутки.
- Editor shell получил:
  - быстрые пресеты provider-ов;
  - быстрые пресеты формата кадра;
  - кнопку `Разобрать код` для извлечения iframe URL/title/size из вставленного snippet;
  - локализованные русские подписи для embed-flow;
  - preview meta вида `Провайдер · Источник · Sandbox`.

### 5. Для длинного HTML добавлен deferred draft commit flow

- Поле `HTML код` для embed больше не пишет в contract на каждый символ.
- Длинный HTML теперь редактируется в локальном черновике inspector-а.
- Для записи черновика в editor state добавлены:
  - кнопка `Применить код`;
  - кнопка `Сбросить`;
  - hotkey `Ctrl+Enter`.
- Это убирает срыв ввода из-за полного re-render inspector-а на каждом `input` событии.

## Остаточные риски

- Несмотря на provider-aware flow, часть внешних embed runtime-ов может шуметь в sandbox iframe консольными `SecurityError`/CORS сообщениями. Для editor preview это ожидаемо, но публичный smoke всё равно обязателен.
- Public runtime smoke на размещённом widget path после этого прохода отдельно не выполнялся; обязательный следующий шаг перед релизом — ручная проверка на публичной странице с реальным Rutube/VK/Kinescope embed.
- Parser сейчас оптимизирован под типовой iframe snippet. Более экзотические provider wrapper-ы, многострочные script bootstrap-вставки и нестандартные embed API могут потребовать отдельного parser pass.
