## Swiss Grid and catalog design-system pass

- Swiss Grid переведен на token-first fallback для typography и базовых цветов: block больше не прибивает заголовки к Helvetica и начинает брать `font_head`, `font_body`, `color_text`, `color_text_muted`, `color_accent` и `color_border` из глобальной дизайн-системы.
- Для catalog browser введен явный contract-флаг наследования глобального стиля:
  - `design.entities.media.inheritGlobalStyle`
  - `design.entities.itemSurface.inheritGlobalStyle`
- Runtime catalog теперь сначала смотрит на эти флаги, а legacy-значения `20`, `22`, `1`, `md` использует только как fallback для старых блоков без нового флага.
- Inspector catalog получил явный режим `Наследовать глобальную дизайн-систему / Локально переопределить` для image radius и card surface, чтобы больше не зависеть от скрытых sentinel values.
- Обновлены package mirrors и template CSS copies.

## Scaffold / validator stage 1

- Добавлен первый исполняемый этап scaffold pipeline:
  - `scripts/nordicblocks-scaffold-block.php`
  - `scripts/nordicblocks-validate-block.php`
  - `scripts/nordicblocks-scaffold-lib.php`
- На этом этапе генератор работает как dry-run preflight: собирает blueprint, проверяет registry/profile/dependency rules, строит план обязательных create/patch files и роняет запуск при нарушении DS guard.
- Validator уже умеет в двух режимах: проверка planned blueprint и structural validation существующего block type по manifest/schema/render, first-wave registration, contract support, package mirror parity и checklist entry.
