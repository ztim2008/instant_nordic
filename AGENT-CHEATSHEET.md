# AGENT CHEATSHEET

Шпаргалка для постановки задач агенту и ведения рабочего дня.

## Как ставить задачу

Хорошая постановка задачи содержит:

1. Что именно нужно получить в конце.
2. Где менять код или документы.
3. Что нельзя ломать.
4. Нужен ли commit, backup, deploy, docs update.

Хороший пример:

`Сделай skeleton компонента landingbuilder в system/controllers. Без UI. Добавь manifest, backend/frontend каркас, SQL-таблицы и краткую документацию. Перед изменениями сделай checkpoint.`

## Открытие дня

В начале дня полезно писать агенту так:

1. `Вот цель дня: ...`
2. `Вот текущий этап: ...`
3. `Вот ограничения: без деплоя / без SQL / только docs / только backend`
4. `Сначала проверь текущее состояние и предложи план`

Готовый шаблон:

`Открытие дня. Цель: <цель>. Текущий этап: <этап>. Ограничения: <ограничения>. Сначала проверь состояние проекта, сделай checkpoint если нужно, потом предложи и выполни план.`

## В течение дня

Лучший режим работы:

1. Давать одну логическую задачу за раз.
2. Просить проверку после каждого заметного шага.
3. Если задача рискованная, явно писать: `сначала сделай backup/checkpoint`.
4. Если нужен результат в docs, явно писать: `обнови документацию по итогам`.

Полезные фразы:

- `Сделай безопасно и с возможностью отката.`
- `Сначала собери контекст, потом меняй.`
- `После правок проверь маршруты, БД и ошибки.`
- `В конце дай короткий отчет и следующий шаг.`

## Закрытие дня

В конце дня писать агенту так:

`Закрытие дня. Собери итог: что сделано, какие файлы изменены, что проверено, какие риски остались, что делать первым следующим сообщением. Если нужно, подготовь checkpoint.`

## Когда просить commit

Просить commit стоит, когда:

- завершен понятный логический этап
- можно откатиться до него
- docs синхронизированы с кодом

Хороший шаблон:

`Этап завершен. Проверь изменения, обнови docs если нужно и сделай commit с нормальным сообщением.`

## Когда просить rollback

Если что-то пошло не так, писать так:

`Оцени, что сломано. Найди ближайшую безопасную точку возврата. Сначала предложи план отката, потом выполни.`
